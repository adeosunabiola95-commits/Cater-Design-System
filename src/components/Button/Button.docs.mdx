# Button

Buttons trigger actions throughout the interface. **Cater Design Systems** — six visual types, three sizes, and icons in four positions.

**Figma mapping** (component set `20:3394`, file `tK5SjqGRgeVr5w5tmxuLDa`)

- **Radius:** Root frame uses **corner radius 999** with shared corner variables → **`rounded-full`** (Radius/full) for every variant, including labelled buttons.
- **Primary:** **Sherwood Green** (`#073D30`, `bg-brand-sherwood-green`) and **Gossip** label (`#CCF8B9`, `text-brand-gossip`); hover darkens to **Sherwood/Chelsea Gem 900** (`#063126`).
- **Focus ring:** White double ring + **Sherwood/Chelsea Gem 300** (`#8DE5D0`) on primary (see `Button.tsx` focus shadow).

## Sizes

Three sizes available.

- **Small**: 8px padding, 14px/21px font, pill corners (Radius/full)
- **Medium**: 10px padding, 16px/24px font (default)
- **Large**: 14px padding, 20px/24px font

## Usage Guidelines

- **Do**: Use Primary buttons for the single most important action on a screen
- **Do**: Use Destructive for delete, remove, or other irreversible actions
- **Do**: Pair Outline or Ghost buttons alongside a Primary button for secondary actions
- **Don't**: Use more than one Primary button in the same section
- **Don't**: Use Destructive for non-dangerous actions
- **Accessibility**: All buttons must have visible text or an `aria-label` when using icon-only mode
- **Accessibility**: Focus states include a visible ring for keyboard navigation

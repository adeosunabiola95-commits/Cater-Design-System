## Usage guidelines

- **Do**: Pick the pattern that matches cognitive load — inform vs confirm vs task vs picker.
- **Do**: Use **Drawer** for supplementary or secondary flows that shouldn’t block the whole viewport.
- **Do**: Provide a clear primary action and a visible dismiss path.
- **Do**: Use `ModalPrimaryActions` when you want cancel + primary footer layout on modals.
- **Don’t**: Nest modals.
- **Accessibility**: `role="dialog"`, `aria-modal="true"`, labelled by title/description when present.
- **Accessibility**: Close control should retain `aria-label`; wire **Escape** to `onClose` in app shell if required.

# Alert, Toast & Banner

Notification components. Each serves a different use case.

---

## Overview

| Component | Use Case | Layout |
|-----------|----------|--------|
| **Alert** | Inline, full-width messages | Single line, colored background, no border |
| **Toast** | Transient feedback | Dark toast with optional highlight, View action, close (Figma `3989:7863`) |
| **Banner** | Title + description notices | Card with icon, border, title + body |

## Use in code

Published entry re-exports these components from the package root:

```tsx
import { Alert, Toast, Banner, Button } from 'cater-design-systems';
```

In this repo, `@/` maps to `src/`. Prefer copying **Show code** on the canvas above for a full working example with state.

---

## When to Use

- **Alert**: Form-level or section-level messages (e.g. "Password reset link sent")
- **Toast**: Quick feedback (e.g. cart added with optional **View** action)
- **Banner**: Announcements or detailed notices (e.g. "New feature released" with description)

# Badge

Badges display short labels or status indicators. Provides 5 colors, 2 sizes, optional outline and icon, and 2 background intensity states.

## Usage Guidelines

- **Do**: Use badges for short labels, counts, or status
- **Do**: Match color to semantic meaning (green=success, red=error, etc.)
- **Do**: Use outline for lower emphasis or when placed on colored backgrounds
- **Don't**: Use badges for long text—keep labels concise
- **Don't**: Mix too many badge colors in a single view

# Checkbox

A checkbox component for selecting one or multiple options from a list. Supports checked, unchecked, and indeterminate states.

Two visual variants:
- **mp (Checboxes mp)**: Outlined style — dark green border, green checkmark on white background
- **saas (Checboxes saas)**: Filled style — grey border when unchecked, green background with white checkmark when checked

## Usage Guidelines

- **Do**: Use checkboxes when users can select zero, one, or multiple items
- **Do**: Use the indeterminate state for a parent checkbox in a nested group
- **Don't**: Use checkboxes when only one option can be selected — use radio buttons instead
- **Accessibility**: Hidden native `<input type="checkbox">` is used for screen reader support
- **Accessibility**: Focus ring triggers via keyboard navigation on the label wrapper

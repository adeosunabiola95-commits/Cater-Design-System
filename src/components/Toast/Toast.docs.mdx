# Toast

Transient notification for cart and workflow feedback. Maps to Figma **Toast** `3989:7863` in [Cater Design System](https://www.figma.com/design/tK5SjqGRgeVr5w5tmxuLDa/Cater-Design-System?node-id=3989-7863).

Dark **Mirage 900** surface, **10px** corner radius, **12px** padding, **21px** gap between message, action, and close. Message is **14px** white body copy with an optional **semibold** highlight; action uses **Brand Gossip** (`#CCF8B9`); close uses the **24×24** cancel icon.

## Usage Guidelines

- **Do**: Use for transient success feedback (e.g. item added to cart)
- **Do**: Keep copy short; use `messageHighlight` for the entity name (product, plan, etc.)
- **Do**: Wire `onAction` when the View control should navigate or open a detail
- **Don't**: Use for errors that need acknowledgment — use Alert or Modal
- **Don't**: Stack many toasts without auto-dismiss — prefer the stacking example pattern
- **Accessibility**: `role="status"`; close button has `aria-label="Close notification"`

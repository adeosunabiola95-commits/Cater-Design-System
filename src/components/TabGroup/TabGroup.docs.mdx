# Tab Group

Interactive tab groups for switching between views or sections.

---

## Variants

### Outline tab

Underline-style tabs. Use for primary navigation.

<Canvas of={TabGroupStories.OutlineTab} sourceState="shown" />

### Buttongroup

<Canvas of={TabGroupStories.Buttongroup} sourceState="shown" />

Tabs stretch to fill the container width equally. Set `fullWidth` when variant is `buttongroup`.

<Canvas of={TabGroupStories.ButtongroupFullWidth} sourceState="shown" />

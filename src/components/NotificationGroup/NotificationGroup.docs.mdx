## Usage Guidelines

- **Do**: Group related notification settings together on a settings page
- **Do**: Provide both a title and description for clarity
- **Don't**: Use for non-toggle actions — this is specifically for on/off preferences
- **Accessibility**: The toggle uses `role="switch"` and `aria-checked` internally

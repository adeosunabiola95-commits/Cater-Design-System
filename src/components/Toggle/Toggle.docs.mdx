# Toggle / Switch

A binary on/off switch for toggling settings or preferences. The knob animates between positions and shows a checkmark icon when in the "on" state.

## Usage Guidelines

- **Do**: Use for binary settings that take effect immediately (e.g., "Enable notifications")
- **Do**: Provide a visible label next to the toggle
- **Don't**: Use for actions that require a "Save" step — use a checkbox instead
- **Accessibility**: Uses `role="switch"` and `aria-checked` for screen readers
- **Accessibility**: Focus ring appears on keyboard navigation via `focus-visible`

# Tags

Tags are pill-shaped labels used for categorization, filtering, or selection. The Cater Design Systems tag system provides 3 types (Base, with checkbox, with flags), 4 states (default, with cancel, hover, with tag), and 2 sizes.

## Usage Guidelines

- **Do**: Use tags for filter chips, category labels, or multi-select options
- **Do**: Use "with cancel" when tags can be removed (e.g. applied filters)
- **Do**: Use "with checkbox" when tags represent selectable options
- **Don't**: Use tags for long text—keep labels short
- **Don't**: Mix too many tag types in a single row

## Size scale

Five heights are used in product UI. Dimensions are taken from **Logo** instances in the Figma file (not invented).

| Token | Frame (px) | Typical use |
| ----- | ---------- | ----------- |
| `xs` | 97×20 | Compact chrome — footers, nested panels |
| `sm` | 140×32 | **Mobile** navigation / top bar |
| `md` | 160×33 | **Tablet** navigation |
| `lg` | 172×36 | **Desktop** navigation (canonical) |
| `xl` | 215×45 | Marketing / hero (sparingly) |

## Usage

```tsx
import { Logo } from '@/components/Logo';

// Desktop nav
<Logo size="lg" />

// Mobile nav
<Logo size="sm" />

// Responsive (two instances — hide/show with Tailwind)
<Logo size="sm" className="sm:hidden" />
<Logo size="lg" className="hidden sm:block" />
```

- Always provide context with `alt` (default: `wecater`).
- Do not stretch the wordmark; pick a **size token** instead of arbitrary width/height.
- Keep clear space around the logo equal to at least **half the wordmark height** on all sides.
- **Icon-only** (~64×64) marks appear in Figma for avatars/app icons; use a dedicated asset when that variant is added to code.

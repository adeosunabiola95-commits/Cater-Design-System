# Radio Button

A radio button for selecting a single option from a mutually exclusive group. Shows a filled inner circle when selected.

Two visual variants:
- **mp (Checboxes mp)**: Outlined style — dark green border, green inner dot
- **saas (Checboxes saas)**: Filled style — grey border when unselected, green background with white inner dot when selected

## Usage Guidelines

- **Do**: Use radio buttons when only one option can be selected from a group
- **Do**: Always group radios using the same `name` attribute and wrap in `role="radiogroup"`
- **Don't**: Use for multi-select scenarios — use checkboxes instead
- **Accessibility**: Hidden native `<input type="radio">` is used for screen reader support
- **Accessibility**: Focus ring triggers via keyboard navigation

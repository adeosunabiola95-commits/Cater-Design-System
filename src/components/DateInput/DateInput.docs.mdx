# DateInput

Date input field that opens the single-date calendar in a popover when clicked. Combines InputField with DatePicker for date selection.

---

## Overview

The DateInput component provides a date picker experience within an input field. Clicking the field opens a popover calendar (single-date variant) for date selection. Supports disabled dates, default values, and sizes (sm, md).

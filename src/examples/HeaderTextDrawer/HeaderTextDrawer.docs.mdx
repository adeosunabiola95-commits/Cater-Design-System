# Header Text Drawer

Add Header Text Drawer pattern. A slide-in panel for adding or editing header text.

---

## Overview

The Header Text Drawer is a right-side drawer with:
- Title "Add Title"
- Centered body content (header text placeholder + description)
- Save button

Use for secondary flows where users add or edit header/title content without leaving the main view.

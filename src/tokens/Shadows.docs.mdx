# Shadows

Shadow tokens define elevation and depth for UI elements.

## Use in code

See **Snippets** below each table row in the canvas, and prefer copying from the **Show code** panel on the story for full context.

## Elevation Scale

Five elevation levels create visual hierarchy and depth. Each level uses one or two `box-shadow` layers with the brand shadow color `rgba(16, 24, 40, opacity)`.

| Token | CSS Value | Usage |
|-------|-----------|-------|
| `xs` | `0 1px 2px rgba(16,24,40,0.05)` | Subtle lift for buttons, inputs |
| `sm` | `0 1px 2px …0.06, 0 1px 3px …0.10` | Cards, dropdowns |
| `md` | `0 2px 4px -2px …0.06, 0 4px 8px -2px …0.10` | Popovers, tooltips |
| `lg` | `0 4px 6px -2px …0.03, 0 12px 16px -4px …0.08` | Modals, dialogs |
| `xl` | `0 8px 8px -4px …0.03, 0 20px 24px -4px …0.08` | Full-page overlays |

## Usage

### Tailwind CSS

```html
<div class="shadow-xs">...</div>
<div class="shadow-sm">...</div>
<div class="shadow-md">...</div>
<div class="shadow-lg">...</div>
<div class="shadow-xl">...</div>
```

### TypeScript Import

```tsx
import { shadows } from '@/tokens';

<div style={{ boxShadow: shadows.md }}>...</div>
```

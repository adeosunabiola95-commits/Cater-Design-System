# Colors

Color tokens synced to **Cater Design Systems** Figma (Brands, Primitives, Semantic / Tokens collections).

## Use in code

**TypeScript** — import maps from this repo (`@/` matches `src/`):

```tsx
import { brands, primitives, semantic } from '@/tokens';

const cardBg = semantic.surface.default;
const primary = primitives.salem['600'];
```

**Tailwind (v4 `@theme`)** — colors from `src/index.css` are available as utilities (see component stories), e.g. `bg-surface-default`, `text-text-title`, `bg-brand-sherwood-green`, `border-border-default`.

**CSS variables** — same file defines `--color-*` for brands, primitives, and semantic tokens (e.g. `var(--color-text-title)`).

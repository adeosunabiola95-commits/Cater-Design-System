# Spacing

Spacing tokens from Figma (**Spacing/**\*). Use **Tokens/Radius** for `Radius/full` (pills); Spacing/999 is deprecated in Figma.

## Use in code

**TypeScript**:

```tsx
import { spacing } from '@/tokens';

<div style={{ padding: spacing[4], gap: spacing[2] }} />
```

**CSS variables** (`src/index.css`):

```css
padding: var(--spacing-4);
gap: var(--spacing-2);
```

Tailwind spacing utilities align to this scale when you use the design-system theme (e.g. `p-4`, `gap-2`).
